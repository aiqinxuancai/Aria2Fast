Aria2的Windows轻量下载客户端，支持BT、HTTP下载及动漫订阅，内嵌了 <a herf="https://mikanani.me/">Mikan</a> 快速动漫订阅添加<br>

> [!TIP]
> **🚀 Aria2Fast 现已推出 Web 版：[Aria2Fast Web](https://github.com/aiqinxuancai/Aria2Fast.Web)**
>
> 支持 Docker / NAS 部署，Windows、macOS 解压即用；电脑和手机浏览器都能随时管理下载。涵盖订阅追番、Mikan 番剧日历、AI 番剧评析与自动分目录、下载完成推送等功能。👉 [立即前往](https://github.com/aiqinxuancai/Aria2Fast.Web)

## 功能
* ⭐任务批量添加
* ⭐支持订阅
* ⭐集成[Mikan](https://mikanani.me/)的动漫源，快速添加订阅
* ⭐可使用内嵌的Aria2下载，无需另外下载配置（当然也可支持远程RPC接口）。
* ⭐任务完成推送。
* ⭐单订阅文件多剧集AI拆分目录（实验性，需OPENAIKEY）
